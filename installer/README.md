# 便携安装器

`MortalHelper-Setup.exe` 适用于 Windows 10 / 11。使用前先退出《活侠传》；安装器会自动查找 Steam 游戏目录，找不到时请点「选择…」，选中游戏目录里的 `Mortal.exe`。

1. 点击「安装 / 更新」。首次安装会安装万象录和所需加载器；如果游戏已有兼容的 BepInEx，安装器会保留它。
2. 从 Steam 启动游戏，按 `Tab` 打开万象录。

更新时再次运行安装器，点击「安装 / 更新」。卸载时点击「卸载万象录」；游戏存档和设置会保留。安装器无需常驻，也无需管理员权限。

如果安装器提示有冲突插件或不兼容的加载器，请按窗口里的说明处理后重试。游戏运行时不能安装或卸载。
