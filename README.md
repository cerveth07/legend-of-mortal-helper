# 活侠·万象录

一个《活侠传》的游戏内辅助 Mod。
按 `Tab` 打开面板，主要功能包括：剧情辅助；战斗辅助；数值编辑；地图查看；存档辅助。

**版本：v1.0.0**


![万象录游戏内面板](docs/shots/story.png)


## 面板功能

面板右上角是总开关。选项提示默认使用「悬停」模式；多数战斗和养成辅助默认关闭，随时存档默认关闭。

| 页面 | 可以做什么 |
|---|---|
| 剧情辅助 | 自主选择掷骰点数与分支；查看不同选项的后果；**在单挑时查看历史对话** |
| 战斗辅助 | 调整单挑时的伤害、命中率、先后手，**支持伤害调整为0以观看部分特殊剧情**；调整群战时的伤害、生命、倒计时 |
| 养成辅助 | 调整练功、锻造、炼丹和日常行动；在人际页修改好感与心上人；**选择本存档中曾经获得的称号**。 |
| 数值编辑 | 分类修改常见游戏数据，**可以修改特殊物品数量**。 |
| 地图 | **查看全天下舆图和崆峒派地图**。 |
| 存档设置 | 随时存档功能，可以在单挑、骰子等页面存档；扩展普通存档格数，可以添加存档备注，切换最近存档排序；**扩展通关故事栏位上限至最多30个**。 |
| 语言 | 切换简体中文、繁體中文、日本語、한국어；尚未翻译的内容显示简体中文。 |

使用选项后果提示时，先收起面板，再把鼠标移到游戏选项上。提示只能显示已解析出的内容，未显示不代表选项没有后果。某些解锁条件支持「一键设为」，使用后会修改当前进度。


## 随时存档须知

**这是实验功能。请先备份自己的存档，并优先使用测试槽位。**在【存档设置】开启后，仍通过游戏的「系统 → 储存游戏」选择编号槽；骰子页面也可点击「存档」。面板会提示当前位置能否保存。

- 剧情：支持可建立恢复起点的对话、选项和骰子等待位置，读档时尝试回到保存位置。
- 单挑：保存的是**本场战斗的开头**。读档后从这场战斗重新开始，不会回到保存时的行动回合。
- 动画、群战、恢复过程，以及无法确认可恢复的剧情位置，不开放随时存档。

实验档旁边有配套文件。**复制、移动或备份这类存档时，要把同槽位的 `.mha`、`.mhstart` 等文件一起带走。**卸载 Mod 前，请先另存一份普通游戏存档。若读档提示缺少配套文件或校验失败，请恢复完整备份，不要反复覆盖原槽位。


## 常用按键

| 按键 | 作用 |
|---|---|
| `Tab` | 展开或收起面板；可在配置中改键。 |
| `F2` | 在存档列表选中槽位后，打开备注编辑。 |
| `F3` | 切换读档列表的最近存档排序。 |


## 安装

适用于 Windows 版《活侠传》，目前按游戏版本 `release_1.0.6000.5` 制作。游戏目录应同时包含 `Mortal.exe` 和 `Mortal_Data`。

**使用安装器（推荐）：**从 [最新版本下载页](https://github.com/cerveth07/legend-of-mortal-helper/releases/latest) 下载 `MortalHelper-Setup.exe`。退出游戏后运行它；安装器会寻找 Steam 游戏，也可手动选择 `Mortal.exe`。点击「安装 / 更新」后从 Steam 启动游戏。安装器自带所需加载器，Windows 需要 .NET Framework 4.7.2 或更新版本。

**手动安装：**先安装 **BepInEx 6.0.0-be.692 Mono x64**，再把 `MortalHelper.dll` 放到游戏目录下的 `BepInEx\plugins\cerveth.mortal.helper\`。完全退出游戏后再复制文件，随后从 Steam 启动游戏。


## 卸载与排查

用安装器安装的版本，可在**退出游戏后**重新运行安装器并选择「卸载万象录」；游戏存档和设置会保留。手动安装的版本，退出游戏后删除 `BepInEx\plugins\cerveth.mortal.helper\MortalHelper.dll`。

如果按 `Tab` 没有看到面板，先确认游戏目录和 BepInEx 版本，再查看 `BepInEx\LogOutput.log` 中的 `MortalHelper` 信息。安装器若提示旧辅助插件冲突，请按提示将它们移出 `BepInEx\plugins\` 后重启游戏。
