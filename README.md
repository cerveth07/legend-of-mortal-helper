# 活侠助手 · 独立重建

计划仓库名：`legend-of-the-mortal-helper`。当前为 **0.1.0 本地开发候选**，尚未建立公开仓库，不能当作原整合版的完整替代品。

本工程从新的源码目录和新的 Git 历史开始编写，不引用旧 `MortalFateHelper.dll` 或 `LOMSave2.dll`。开发者已阅读过旧实现；这是按功能需求重新设计的工程，不声称为未经接触原代码的洁净室开发，也不是版权零风险证明。来源和保留决策见 [PROVENANCE.md](PROVENANCE.md)。

## 当前实现

| 内容 | 当前状态 |
|---|---|
| 配置与主面板 | 新插件标识 `cerveth.mortal.helper`；Tab 展开/收起，窗口拖动、缩放和位置保存 |
| 原生轮盘 | 自然掷骰、指定基础点数、直接选项；过期回调/重复提交保护；重掷调用原生扣点流程 |
| 选项提示 | 默认关闭；受限词法解析，支持注释、引号与 Lua 长字符串；不明确控制流停止分析；仅显示已识别直接效果及已有原生轮盘条件 |
| 单挑辅助 | 默认关闭；主角生命/气力不因普通扣减降低、最高闪避、敌方有效受伤时一击必杀；保留原生剧情机制 |
| 单挑回想 | 记录实际调用的对白，最多 500 条；新单挑清空；不暂停游戏 |
| 属性编辑 | 26 项白名单；只在自由活动场景空闲且无原生面板占用时允许；重新核对对象和当前值 |
| 好感编辑 | 仅已登场角色，校验当前值和各角色上限 |
| 恢复底层 | 固定字段格式、16 MiB 文件预算、最多 100000 事件、严格 UTF-8、损坏检查、备份替换（替换不可用时回退为复制，损坏主档不当备份）、录制/重放状态机、恢复控制器（预检 → 基线 → 重放 → 校验，失败锁操作） |
| 剧情/单挑精确恢复 | **尚未接入游戏**；底层通过测试不代表已经能恢复玩家进度 |

新的恢复格式使用 `.mhr`，把基线、事件和目标校验信息放进一个文件。没有启用旧 `.loms` / `.duel` 读取路径；不使用 BinaryFormatter；普通 SHA-256 只用于检测损坏，不是安全签名。

还没有完成原版所有功能：完整条件/事件/任务提示、强制事件、跨周目分支记录、群战辅助、养成辅助、心上人编辑、物品数量、速度、存档槽整合和精确恢复仍在待办中。不得把本候选宣传为功能对等或已可安全升级。[剩余工作和验收](docs/IMPLEMENTATION.md)

## 构建和测试

需要 Windows、Python 3、.NET 8 运行时、Roslyn 4.12 `csc.dll`、本机游戏，以及 BepInEx 6.0.0-be.692 Mono 的 `core` 目录。脚本不下载依赖，也不安装到游戏。

```powershell
python build.py --game "D:\steam\steamapps\common\LegendOfMortal" --loader "本地\BepInEx\core" --compiler "本地\Roslyn\tasks\netcore\bincore\csc.dll" --test
```

输出位于被 Git 忽略的 `artifacts/`。构建记录包含源码与本机依赖的 SHA-256，不包含游戏程序集本体。离线检查只使用人工构造的数据和临时目录，不读取玩家存档。

本轮已针对本机 Steam Build 26021712 编译，编译器警告视为错误。测试报告见 [VALIDATION.md](docs/VALIDATION.md)。2026-10-19 完成启动级实机验证：加载器兼容、16 个 Harmony 补丁全部解析、无运行期异常、Tab 可打开面板且中文正常渲染；轮盘交互、面板拖动收起、辅助效果和恢复闭环仍未验证。

## 开发候选的安装边界

当前不提供面向普通玩家的整合安装包。`artifacts/MortalHelper.dll` 仅供隔离测试；不要把它覆盖安装到旧整合版所在环境。启动时若在插件目录发现旧辅助 DLL，会停用本插件并报告冲突。

实际游戏验证应使用备份周目及独立测试环境，先核对 [人工验收清单](docs/IMPLEMENTATION.md)，再决定是否发布。用户安装目录本次未修改。
