# 随时存档验证范围

本文件区分历史实机验证、当前 v1.0.0 构建检查和仍需验证的场景。随时存档在 v1.0.0 中继续默认关闭，并标为实验功能。

## 已有实机证据

此前的游戏构建在隔离存档环境中，通过实际存读档界面完成下列往返：

| 场景 | 已验证的结果 |
|---|---|
| 剧情台词和选项 | 保存、完全退出、重新启动、读取后回到目标等待位置；状态校验通过，并能继续推进、再次保存和读取。 |
| 骰子等待页 | 掷骰前、普通结果、重掷、范围变化和直接选择分支均曾完成冷启动读取及后续推进；动画期间拒绝存档。 |
| 原生存档边界 | 关闭实验功能后，原生保存与冷启动读取正常；实验附档缺失或损坏时明确拒绝错误配对，随后仍能读取有效原生档。 |
| 旧单挑精确档 | 旧方案曾完成首回合与多行动冷启动读取、再次保存及战斗结束。v1.0.0 的新单挑存档改为“战斗开头”，此项历史结果不能作为新方案的验收。 |

以上证据对应此前各自的构建，不等于 v1.0.0 发布包已经完成相同的实机闭环。游戏版本基线为 `release_1.0.6000.5`、Steam Build `26073097`、Unity `2020.3.49f1`、BepInEx `6.0.0-be.692`。原始测试日志、游戏资产和玩家存档不随源码分发。

## 当前版本边界

- 剧情仅在可建立恢复起点的台词、选项及骰子稳定等待位置开放；未知或无法核验的 Lua 状态、动画、群战和恢复过程中拒绝保存。
- 单挑只保存本场战斗开头，读取后从战斗开头重来，不能恢复到保存时的行动回合。旧 `.mhduel` 精确档保留兼容读取路径。
- 实验档依赖同槽的原生 `.dat` 与附档或标记；复制、移动、备份时须保持配对。缺少必需件或校验失败时不能当作恢复成功。
- 本次 v1.0.0 发布仅完成编译、离线契约、打包及安装器后端测试；尚未对新发布包执行剧情与单挑的完整冷启动存读回归。所有剧本、战斗和辅助开关组合也未穷尽测试。

如果恢复失败，请读取已确认有效的普通原生档或恢复完整备份；不要反复覆盖故障槽位。
