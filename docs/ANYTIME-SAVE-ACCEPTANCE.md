## 已确认并修复的问题

1. 剧情脚本入口应使用原生 `StartStoryScript`；`CurrentStoryScript` 不由原生保存逻辑写入。
2. `dynamic`、`json` 及 `package` 属于运行库。按实际模块定义和初始对象身份识别，不通过跳过所有自定义表来开放存档。
3. 剧情自有状态支持有界嵌套标量表；清理 MoonSharp 的删除墓碑，拒绝循环、别名、元表和不支持对象。原始全局 API 改绑或新增不支持对象也拒绝保存。
4. 插件自定义数组、列表改为显式有界附档编码，保留双精度及随机调用数据，不依赖实机可能遗漏字段的 Unity 序列化。
5. 原生加载后的场景初始化会覆盖资产型旗标；最终发布构建曾重现单挑首停点仅S9200不同。于剧情脚本入口或单挑原生Start协程执行前恢复原生开场 baseline 旗标，随后正常重放；最终仍核对完整目标，不忽略天气字段，也不按期望目标强制改值。
6. 原生旗标集合合法地重复引用同一资产。恢复按原生集合顺序及资产身份验证，冲突值仍拒绝。
7. 单挑行动点改为观察实际协程状态机完成；恢复后保留开场原生数据，供再次保存。
8. 战斗场景没有原生储存面板。补充明确的储存模式，复用编号列表，隐藏删除入口、确认覆盖，禁止误走原生读取，并在退出后恢复读取界面。
9. 事务提交或回退决定持久化后才清理备份；中断及持久化失败保留恢复材料。
