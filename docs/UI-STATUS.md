## 本轮布局调整

- **统一可用宽度**：先从面板实际宽度扣除窗口内边距得到 viewport；宽面板的内容列设上限并居中。正文 body 再从 viewport 扣除滚动条及其水平 margin，所有说明、编辑行和列宽使用同一 body 宽度。
- **滚动条只预留一次**：短页和长页均预留竖向滚动条，避免内容变长或 Layout/Repaint 切换时宽度跳变。不能再用额外的固定百分比重复扣减。
- **消除隐含横向占位**：正文标签、按钮、输入框等参与行宽预算的控件，其左右 margin 归零，间隔由行布局显式安排；文字标签的左右 padding 归零，上下空间按字体行高保留。按钮保留其自身必要的内边距，不宣称所有控件的 padding 都经过逐项测量。
- **主次导航分别适配**：五个主页签按实际文字测量决定列数，每个 slot 固定等宽，放不下时换行；子页签及四类物品导航按 body 宽度分配槽位，避免固定宽度总和超出窄面板。
- **编辑行支持两种结构**：属性、物品和好感在窄面板分为两行，第一行名称与当前值/范围，第二行输入与应用；宽面板使用一行布局。输入示例、数值范围和应用按钮按实际样式测量预留宽度，再分配名称剩余宽度。
- **完整名称换行**：属性、物品与人物名称保留完整文本，由列宽和换行承担长名称，不再依赖省略号掩盖溢出。
- **速度显示独立预留**：先测量倍率文字，再从正文宽度中扣除倍率与间隔分配滑杆，避免滑杆把倍率挤出内容列。

这些是代码层面的布局规则；其显示效果仍以当前构建的真实截图为准。

## 小字底部裁切：前次验收更正

前次176张截图虽然覆盖横向溢出与各页布局，却漏检了控件内部的字形底部裁切，不能视为“所有文字完整”的通过证据。用户指出剧情说明“收起面板后悬停选项生效……”底部笔画被削，已在原尺寸和3倍最近邻放大图中复现。

运行时稳定后的TextMetrics：Description字号14、lineHeight18，旧padding0使CalcHeight只有14；Entry/普通label字号16、lineHeight20，旧CalcHeight只有16。上下padding清零配合Clip会削掉字底。仅补padding仍会被内部Clip扣回，所以现在同时保留lineHeight-fontSize的底部空间，并让字形Overflow绘入该留白。换行宽度沿用原预算，外层滚动区照常裁切。导航和按钮已有固定高度仍保留；没有调整字体、字号和颜色。

新验收同时检查：原尺寸/最近邻放大后的字形上下笔画、字体行高与预留空间、各行是否侵入相邻控件、右侧是否出界。不能只凭整句能辨认就判定没有裁切。

## 留白、滚动条、开关与区段跳转

本轮在前述宽度预算与字形修复基础上调整布局，背景纹理、颜色与透明度不动，`PanelStyle.cs` 未修改。截图背后的游戏画面可能随时间变化，不表示插件背景样式发生变化。

- **空消息不占位**：Status 为空时移除原占位；有消息时显示在滚动正文下方，不再把顶部正文向下推。消息在 Layout 阶段取得快照，供对应 Repaint 使用，避免同一轮中出现/消失导致控件拓扑不一致。
- **区段与子页间距**：每页首个 Section 上方为 6px，后续 Section 为 24px；ViewTabs 后只保留共享的 6px，取消页面额外叠加的 8px。间距随界面 scale 缩放。
- **短页隐藏滚动条**：正文仍使用固定 gutter 预算，避免宽度跳变；`alwaysShowVertical=false`，实际内容不足一页时不绘制滚动条。这是在保留统一宽度预算下调整显示行为。
- **开关间距**：开关前后各保留 8px，从原行内预算重新分配，整行总宽度不增加。
- **数值页固定导航**：顶部提供属性、物品、速度三个区段跳转按钮。区段坐标在 Repaint 缓存，点击通过 Defer 延后执行，避免在当前 IMGUI 绘制中切换滚动位置；正文滚动时导航仍留在顶部。
- **重新展开的页签字号**：从收起徽章打开面板的过渡期间，不再根据过渡宽度修改共享 Tab 字号，避免临时窄宽度把后续页签字号持续压小。

前轮对小字底部笔画、字体行高与留白的验证仍有效，但前轮截图不能证明上述新布局已验收。新批次须重新检查空/有消息、短/长页、开关间隔和三个实际区段跳转。
